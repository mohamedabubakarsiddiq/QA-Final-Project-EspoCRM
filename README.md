\# EspoCRM QA Automation Project



\## Project Overview



This project is a complete Software Quality Assurance and Test Automation project based on EspoCRM.



The project covers Manual Testing, UI Automation, API Testing, Database Testing, Version Control, and CI/CD.



\## Application Under Test



EspoCRM 10.0.4



Local URL:



http://localhost:8081



\## Project Objectives



\- Perform functional and regression testing

\- Design comprehensive test scenarios and test cases

\- Maintain Requirements Traceability Matrix (RTM)

\- Report and track defects

\- Automate UI test cases using Selenium WebDriver

\- Implement TestNG test framework

\- Apply Page Object Model (POM)

\- Perform API testing

\- Perform database validation using SQL

\- Integrate automation with Maven

\- Manage source code using Git and GitHub

\- Execute automated tests through Jenkins

\- Generate test execution reports
